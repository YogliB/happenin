# Security Policy

## Supported Versions

Security updates are applied to the latest release and the current default branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, open a private [security advisory](https://github.com/YogliB/happenin/security/advisories/new) or contact the maintainer with:

- A description of the issue.
- Steps to reproduce, if applicable.
- The file or command involved.

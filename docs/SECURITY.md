# Security Policy

## Supported Versions

Security updates are applied to the latest release and the current default branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, open a private [security advisory](https://github.com/YogliB/happenin/security/advisories/new) or email <me@yogev.dev> with:

- The affected version.
- A description of the impact.
- Steps to reproduce, if applicable.
- The file or command involved.
